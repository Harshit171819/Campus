terminal About this Event

Ready to push code into production? AI Build Night is our premier hands-on campus hackathon designed to take you from a raw prompt to a fully deployable generative AI application in a single evening.

Whether you are testing the frontier of function-calling autonomous agents, synthetic audio workflows, or custom vector embeddings, you will be paired with industry mentors and top university researchers. Free API credits, pizza, and refreshments are included for all registered attendees.
